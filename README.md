# 깍깍이 🐦‍⬛💬

> 까마귀 깍깍이가 내 번호로 문자를 콕콕 보내드려요 (재잘이의 동생 앱)

내 컴퓨터에서 쓰는 **문자 보내기 앱**이에요. 받는 사람에게는 **내 휴대폰 번호**로 문자가 가요.

- 📇 **연락처와 그룹**: 이름·번호를 저장하고 "가족", "모임"처럼 그룹으로 묶어요
- 📥 **구글 연락처 가져오기**: 구글 연락처에서 내보낸 파일을 그대로 넣어요 (라벨은 그룹이 돼요)
- ✅ **받는 사람 고르기**: 한 명씩, 또는 그룹을 눌러 한꺼번에
- 👤 **이름 자동으로 넣기**: `{이름}님 안녕하세요` → 사람마다 "영희님", "철수님"
- 📝 **자주 쓰는 문구**: 저장해 두고 버튼 한 번에 불러와요
- ⏰ **예약 보내기**: 그 시각에 솔라피가 대신 보내줘요. **컴퓨터가 꺼져 있어도 돼요**
- 💰 **보내기 전 확인**: 몇 명에게, 짧은/긴 문자, 예상 비용을 먼저 보여줘요
- 🕘 **보낸 기록**: 누구에게 언제 보냈는지, 잘 받았는지 (예약 취소도 여기서)
- 🔒 연락처와 열쇠는 **내 컴퓨터의 `data` 폴더에만** 저장돼요. GitHub에는 절대 올라가지 않아요

문자는 국내 문자 발송 서비스 **솔라피(SOLAPI)** 를 거쳐 보내요. (컴퓨터는 혼자서 문자를 보낼 수 없어서 통신사와 연결된 서비스가 필요해요)

## 처음 한 번만 하는 준비

### 1. 깍깍이 켜기

1. <https://nodejs.org> 에서 **LTS** 버전을 설치합니다. (재잘이 때 설치했으면 건너뛰기)
2. 이 폴더의 **`start.bat`** 을 더블클릭합니다. (경고 창이 뜨면 **추가 정보 → 실행**)
3. 검은 창이 뜨고 크롬에 깍깍이 화면이 열려요. **검은 창은 닫지 마세요.** 닫으면 꺼져요.

**바탕화면 바로가기:** **`make-shortcut.bat`** 을 더블클릭하면 바탕화면에 까마귀 아이콘 **[깍깍이]** 가 생겨요.

> 재잘이와 깍깍이를 **동시에 켜도 괜찮아요.** (재잘이는 3000번, 깍깍이는 3001번 문을 써요)

### 2. 솔라피 준비 (같이 한 단계씩 해요)

1. 솔라피 홈페이지에 가입하고 **충전**해요. (미리 충전하는 방식)
2. **발신번호 등록**: 내 휴대폰 번호를 등록하고 본인 인증을 해요.
   우리나라는 미리 등록한 번호로만 문자를 보낼 수 있어요 (발신번호 사전등록제).
3. **API 키 만들기**: API 키와 API 시크릿을 받아요.
4. 깍깍이 **⚙️ 설정** 에 API 키·시크릿·내 휴대폰 번호를 넣고 **저장** → "연결됨"이 뜨면 성공!
5. **📱 내 번호로 시험 문자 보내기** 로 내 휴대폰에 잘 오는지 확인해요.

### 3. 구글 연락처 가져오기

1. 크롬에서 <https://contacts.google.com> 을 열어요.
2. 목록 위쪽의 **내보내기** 버튼 → **Google CSV** → **내보내기**. 다운로드 폴더에 `contacts.csv` 가 생겨요.
3. 깍깍이 **📇 연락처 → 📥 구글 연락처 가져오기 → 파일 고르기** 에서 그 파일을 골라요.

- 구글의 **라벨**(가족, 동창 등)은 깍깍이의 **그룹**이 돼요.
- 휴대폰 번호가 없는 사람(집 전화만 있는 사람)은 건너뛰어요.
- 연락처가 바뀌면 다시 내보내서 가져오면 돼요. 이미 있는 번호는 다시 넣지 않아요.

## 알아두면 좋은 것

- **짧은 문자(SMS)**: 한글 약 45자(90바이트)까지. **긴 문자(LMS)**: 한글 약 1000자(2000바이트)까지, 요금이 조금 더 들어요.
  한글은 2바이트, 영어·숫자·띄어쓰기는 1바이트로 세요. 글 쓰는 칸 아래에 바로 보여줘요.
- 같은 글이라도 `{이름}` 때문에 이름이 긴 사람만 긴 문자가 될 수 있어요. 보내기 전 확인 창에서 알려줘요.
- **이모지**(😊 같은 그림 글자)는 받는 휴대폰에서 깨져 보일 수 있어요.
- 예상 비용은 **⚙️ 설정 → 예상 요금**에 넣은 금액으로 계산해요. 솔라피 요금표를 보고 맞춰 주세요.
- 예약은 **3분 뒤부터 6개월 안**까지 할 수 있어요.
- 광고 문자는 보내지 않아요. (혹시 나중에 광고성 문자를 보내려면 받는 사람 동의, "(광고)" 표시, 밤 9시~아침 8시 금지 같은 규칙이 있어요)

## 개발 메모

- Node.js 내장 기능만 사용 (외부 라이브러리 없음). 테스트: `npm test`
- 내 컴퓨터 주소(`127.0.0.1:3001`)에서만 열리고, 다른 웹사이트에서 온 요청은 막아요.
- `src/server.js` 서버 · `src/solapi.js` 솔라피 연결 (HMAC-SHA256 인증, `messages/v4/send-many/detail`) · `src/sms.js` 길이·종류·비용 · `src/contacts-import.js` 구글 연락처 · `src/store.js` `data/` 저장
- 아이콘: `python3 tools/make-icon.py tools/icon.ico public/icon.png` · 소리: `python3 tools/make-sound.py public/kkak.wav`
